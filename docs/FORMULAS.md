# Расчётная модель и формулы

## Балочный конечный элемент

Используется линейная теория Эйлера—Бернулли: малые перемещения, плоские сечения остаются плоскими, деформации сдвига не учитываются. В каждом узле две степени свободы: поперечное перемещение `v` и угол поворота `θ`.

```text
        EI │ 12/L³   6/L²  -12/L³   6/L² │
k =        │  6/L²   4/L    -6/L²   2/L  │
           │-12/L³  -6/L²   12/L³  -6/L² │
           │  6/L²   2/L    -6/L²   4/L  │
```

Для линейно изменяющейся нагрузки используются согласованные узловые силы. Глобальная система `K·u = F` решается исключением Гаусса с частичным выбором главного элемента. Реакции: `R = K·u − F`.

## Прочность и жёсткость

```text
σ = M / W
f_d = f_y / γ_M
η_strength = |σ|max / f_d
f_limit = L / n
η_deflection = |f|max / f_limit
```

Проверка пройдена при `η_strength ≤ 1` и `η_deflection ≤ 1`.

## Ферма

```text
N = EA/L · [-c -s c s] · u_e
σ = N/A
```

Положительная продольная сила означает растяжение.

## Колонна

```text
N_cr = π²EI / (μL)²
λ = μL / i
i = √(I/A)
```

`μ`: 2.0 для защемление–свободный край, 1.0 для шарнир–шарнир, 0.7 для защемление–шарнир, 0.5 для двух защемлений.

## Знаки и единицы

- входные силы балки положительны вниз;
- вертикальная реакция положительна вверх;
- приложенный момент положителен против часовой стрелки;
- ядро использует Н, м, Па;
- JSON и UI принимают кН, кН/м, кН·м.

Модель не учитывает кручение, сдвиг Тимошенко, пластичность, контакт, динамику, усталость, местную устойчивость, пространственные эффекты и нелинейность второго порядка.
