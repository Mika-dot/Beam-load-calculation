# Внесение изменений

1. Создайте отдельную ветку.
2. Не добавляйте `bin`, `obj`, исполняемые файлы и сгенерированные отчёты.
3. Для изменения алгоритма добавьте проверку в `EngineeringCalculator.Tests`.
4. Выполните Release-сборку и весь набор проверок.
5. Обновите документацию при изменении единиц, знаков, допущений или API.

Nullable-контекст включён, предупреждения компилятора считаются ошибками, внешние зависимости добавляются только при обоснованной необходимости.
